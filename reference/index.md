# Package index

## Blinding data

The two functions that do the work.
[`blind_file()`](https://agallinat.github.io/datablinder/reference/blind_file.md)
is
[`blind_data()`](https://agallinat.github.io/datablinder/reference/blind_data.md)
with a reader and a writer around it.

- [`blind_file()`](https://agallinat.github.io/datablinder/reference/blind_file.md)
  : Blind a data file
- [`blind_data()`](https://agallinat.github.io/datablinder/reference/blind_data.md)
  : Blind a data frame
- [`format(`*`<blind_summary>`*`)`](https://agallinat.github.io/datablinder/reference/blind_summary.md)
  [`print(`*`<blind_summary>`*`)`](https://agallinat.github.io/datablinder/reference/blind_summary.md)
  : The summary of a blinded table
